# Veto Antigravity Plugin Bundle

This directory packages **Veto** as an Antigravity plugin bundle (`plugin.json`, `mcp_config.json`, `skills/veto/SKILL.md`, and `rules/AGENTS.md`).

## Installing Locally

Copy `plugins/veto/` to `~/.gemini/config/plugins/veto/` after installing the `veto` CLI (`uv tool install .` or `pip install -e .`), then enable **Veto AI Agent Firewall** in Antigravity Customizations.

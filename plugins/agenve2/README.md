# AgenVe2 Antigravity Plugin Bundle

This directory packages **AgenVe2** as an Antigravity plugin bundle (`plugin.json`, `mcp_config.json`, `skills/agenve2/SKILL.md`, and `rules/AGENTS.md`).

## Installing Locally

Copy `plugins/agenve2/` to `~/.gemini/config/plugins/agenve2/` after installing the `agenve2` CLI (`uv tool install .` or `pip install -e .`), then enable **AgenVe2 AI Agent Firewall** in Antigravity Customizations.
